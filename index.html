01 / About

A little background

I'm a software engineer in Dallas–Fort Worth with a B.S. in Computer Science from East Texas A&M University (minor in Mathematics) and 6+ years of professional experience on e-commerce and warehouse systems. Most developers know one side or the other. I've built both, and the integration between them.

At Traxxas I work across the whole path of an order. On the storefront, I build custom Magento 2 / Adobe Commerce modules (plugins, observers, service contracts, GraphQL resolvers, webhooks) and Hyvä theme features with Algolia search. Behind it, I designed the RabbitMQ framework that connects Magento to our Oracle WMS, ERP and CMS. Its consumers are idempotent, process parents before children, and send failures to an error queue that alerts the team instead of losing a message. It moves tens of thousands of orders a day.

I also build the Oracle APEX / PL/SQL apps associates use on Zebra handhelds: case picking, cycle counts, restocking, item dimensioning, and UPS, USPS and FedEx label printing. I've spent time on the warehouse floor watching how those tools actually get used, and some of my best features came from that, like a confirmation scan that catches the wrong case before it ships, or a label that prints the moment the associate hits submit.

I own deployments to Adobe Commerce Cloud, lead code reviews, mentor a junior developer, and serve as Scrum Master for my team. We haven't had a significant site outage since I took over deployments, and every deploy now runs automated checks that compare the live site against the system of record and republish anything missing. I use AI where it measurably helps: our feature testing runs Playwright alongside Claude agents that review failures and explain them in plain English.

Before Traxxas I was at Innovation First International, where I worked on a Magento 1 to 2 migration, built Laravel applications, integrated Algolia Instant Search into Magento 2 (experience I've since carried into Hyvä work at Traxxas), and built the Vue.js power capacity calculator in my projects below.

03 / Projects

Things I've built

Most of my work is closed-source production code at Traxxas, so these describe how each system works and what it does rather than linking to code. The calculator at the end is a live demo you can try.

Integration · Traxxas

Event-driven commerce ↔ WMS/ERP integration

A RabbitMQ framework connecting Magento 2 to an Oracle system of record (WMS, ERP and CMS). New feeds extend a generic base module and register in an action pool instead of building a new pipeline. Consumers upsert by the source system's IDs, process parents before children, and route failures to an error queue that alerts the team. It carries tens of thousands of orders a day.

Shows: integration design built for retries, ordering and failure.

PHPMagento 2RabbitMQ OracleREST
E-commerce · Traxxas

Power-Up trade-in program

A B2C trade-in program on Magento 2: customers pick an old part to send in and buy the upgrade. I built the core flow. The trade-in catalog arrives from Oracle over RabbitMQ, the storefront validates stock and region on add-to-cart, and flagged cart and order lines carry through to the ERP, which applies the credit once the old part comes back.

Shows: a full-stack feature from admin data to ERP order publishing.

Magento 2PHPRabbitMQ Oracle APEXAJAX
Warehouse · Traxxas

Case-pick app for large dealer orders

A Zebra handheld app for picking full cases. Associates scan the bin, the case and the label, and a confirmation scan has to match before inventory moves. Every pick is logged against the package and shipment line. Version 2 moved processing to background jobs so the handheld responds instantly, and made it idempotent so a double scan can't double-count. Large dealer orders now ship the same day they're released.

Shows: product thinking alongside operations, and idempotent design.

Oracle PL/SQLOracle APEX Zebra HandheldsBackground Jobs
Reliability · Traxxas

Post-deploy checks with automatic recovery

Every Adobe Commerce Cloud deploy triggers Jenkins, running in Docker, to run Selenium regression tests and a scrape of the live site. The results are compared against what the system of record says should be live, the team is alerted on drift, and missing data is republished automatically. After every deploy, we know within minutes if anything broke.

Shows: ownership of release quality, testing the real deployed build.

AI tooling · Traxxas

AI-assisted test automation

Two pieces, both in production. A Python script orchestrates Claude Code agents that exercise new features on our Magento 2.4.8 site. A hybrid suite runs deterministic Playwright tests, and a Claude agent (Anthropic SDK) reviews each failure and reports a plain-English explanation, a severity and suggested fixes. I chose the hybrid design after measuring its time and cost against an all-agent approach.

Shows: using AI where it measurably helps, not everywhere.

Warehouse · Traxxas

Item dimensioning with Cubiscan

An app that finds products missing dimensions and guides an associate through measuring and weighing them on a Cubiscan. The data syncs into Oracle so our Packsize box-sizing system picks the right box at pack-out.

Warehouse · Traxxas

Carrier label integration

An Oracle APEX form builds the UPS shipping request in PL/SQL, sends it through a message queue to the carrier, parses the response and sends the ZPL label straight to a Zebra network printer. It supports multi-package shipments and prepaid return labels, and the label prints seconds after the associate hits submit. I also integrated USPS and FedEx.

Shows: end-to-end integration from a form to physical hardware.
